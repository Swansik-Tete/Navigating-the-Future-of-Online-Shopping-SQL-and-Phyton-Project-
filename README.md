# E-Commerce-Sales-Analysis

## Overview
This project analyzes e-commerce sales data using SQL and Python to understand business performance, customer behavior, seller contribution, and revenue trends.

---

## Tools Used
- SQL
- MySQL Workbench
- Python
- Pandas
- Matplotlib
- Google Colab

---

## Dataset
- CUSTOMERS.csv
- SELLERS.csv
- ORDER_ITEMS.csv
- PAYMENTS.csv
- ORDERS.csv
- PRODUCTS.csv

---

## Analysis Performed
- Sales analysis
- Revenue trends
- Seller performance
- Customer analysis
- Product category analysis
- Customer retention analysis
- Year-over-year growth analysis

---

## Features
- SQL query analysis
- Data visualization
- Revenue tracking
- Customer behavior insights
- Seller ranking analysis

---

## How to Run
1. Import datasets into MySQL Workbench
2. Run SQL queries
3. Open Python notebook in Google Colab or Jupyter Notebook
4. Run analysis and visualization files
